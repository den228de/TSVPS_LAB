# 🔬 ПОЛНАЯ ВЕРСИЯ - Анализ алгоритмов разделения камней

## Это полная версия приложения для преподавателя

## 🎓 Для защиты лабораторной работы

### Что говорить преподавателю:

1. **Задача**: Разделить камни на две кучи с минимальной разницей весов

2. **Алгоритм 1 - Полный перебор**:
   - Проверяет все 2^n комбинаций
   - Использует битовые маски
   - Гарантирует оптимальное решение
   - Сложность: O(2^n)
   - Медленный для больших n

3. **Алгоритм 2 - Эвристика**:
   - Сортирует камни пузырьком
   - Жадно распределяет в более легкую кучу
   - Сложность: O(n²)
   - Быстрый, но не гарантирует оптимум

4. **Результаты**:
   - Эвристика отличается от оптимума на 0.6-1.1%
   - Для практики это приемлемо
   - Выигрыш в скорости огромный (секунды vs минуты)
