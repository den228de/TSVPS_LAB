# Поиск клик в графе

Программа для поиска максимальной клики в графе с графическим интерфейсом.

## 📁 Файлы проекта

- **clique_finder.py** - основной модуль с алгоритмами поиска клик
- **clique_gui.py** - графический интерфейс (GUI)
- **build_clique.bat** - скрипт для сборки standalone приложения
- **requirements.txt** - список зависимостей
- **ЗАЩИТА_КЛИКА.md** - подробное руководство для защиты работы

## 🚀 Быстрый старт

### Вариант 1: Запуск из исходников

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите GUI приложение:
```bash
python clique_gui.py
```

### Вариант 2: Создание EXE файла

1. Запустите скрипт сборки:
```bash
build_clique.bat
```

2. Найдите готовое приложение в папке `dist\CliqueFinderGUI.exe`

3. Скопируйте этот файл на любой компьютер с Windows и запустите!

## 📖 Использование

1. **Введите параметры:**
   - Количество вершин (например, 8)
   - Количество рёбер (например, 15)
   - Значение B (например, 3)

2. **Нажмите "Найти клики"**

3. **Результаты:**
   - В левой панели отображается процесс поиска
   - В правой панели - визуализация графа
   - Внизу слева - матрица смежности

## 🎨 Визуализация

- 🔵 **Синие вершины** - обычные вершины
- 🟠 **Оранжевые вершины** - клика размером больше B
- 🔴 **Красные вершины** - максимальная клика

## 📚 Что такое клика?

**Клика** - это подмножество вершин графа, в котором каждая пара вершин соединена ребром.

Программа решает две задачи:
1. Найти клику размером больше заданного числа B
2. Найти максимальную клику в графе

## 🛠️ Технические детали

- **Язык:** Python 3.7+
- **GUI:** tkinter
- **Визуализация:** matplotlib
- **Сложность:** O(2^n × n²) в худшем случае
