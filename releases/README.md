# Готовые приложения (Releases)

Все приложения собраны и готовы к запуску на любом компьютере с Windows.  
**Python НЕ требуется!**

---

## Список приложений

### 1. 🔷 [1_StonePartition.exe](1_StonePartition.exe)
**Сортировка камней (быстрая версия)**  
Размер: ~40 МБ  
Сравнение алгоритмов разбиения камней на кучи с ускоренными тестами.

---

### 2. 🔶 [2_StonePartition_Full.exe](2_StonePartition_Full.exe)
**Сортировка камней (полная версия)**  
Размер: ~40 МБ  
Расширенное тестирование алгоритмов с полным набором данных.

---

### 3. 🔷 [3_CliqueFinderGUI.exe](3_CliqueFinderGUI.exe)
**Поиск клик в графе**  
Размер: ~38 МБ  
Поиск максимальных клик в неориентированном графе с визуализацией.

---

### 4. 🔶 [4_HypercubeSimulator.exe](4_HypercubeSimulator.exe)
**Симуляция сети гиперкубов**  
Размер: ~38 МБ  
Моделирование топологии гиперкубов и поиск кратчайших путей (BFS).

---

### 5. 🔷 [5_NeuralNetwork.exe](5_NeuralNetwork.exe)
**Нейронная сеть**  
Размер: ~38 МБ  
Обучение и тестирование нейронной сети с визуализацией результатов.

---

## Как использовать

1. Скачайте нужный .exe файл
2. Дважды кликните на файл
3. Приложение запустится автоматически

**Примечание**: При первом запуске Windows может показать предупреждение SmartScreen. Нажмите "Подробнее" → "Выполнить в любом случае".
