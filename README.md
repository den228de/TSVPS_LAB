# Лабораторные работы

Репозиторий с лабораторными работами по различным алгоритмам и структурам данных.

## Проекты

### 1. 🔷 Сортировка камней (Stone Partition)
Приложение для сравнения алгоритмов разбиения камней на кучи.

**Технологии**: Python, tkinter, matplotlib  
**Папка**: корень репозитория  
**Запуск**: `python app.py`

---

### 2. 🔶 Поиск клик в графе
Приложение для поиска максимальных клик в неориентированном графе.

**Технологии**: Python, tkinter, matplotlib, networkx  
**Папка**: `Клики/`  
**Запуск**: `python clique_gui.py`

---

### 3. 🔷 Симуляция сети гиперкубов
Приложение для моделирования топологии гиперкубов и поиска кратчайших путей.

**Технологии**: Python, tkinter, matplotlib, networkx  
**Папка**: `кубы/`  
**Запуск**: `python hypercube_gui.py`

---

### 4. 🔶 Нейронная сеть
Приложение для обучения и тестирования нейронной сети.

**Технологии**: Python, tkinter, matplotlib, numpy  
**Папка**: `нейронка/`  
**Запуск**: `python neural_network_gui.py`

---

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Сборка .exe файлов

Каждый проект содержит bat-файл для сборки исполняемого файла:

- `build_exe.bat` - сортировка камней
- `Клики/build_clique.bat` - поиск клик
- `кубы/build_hypercube.bat` - гиперкубы
- `нейронка/build_neural_network.bat` - нейронная сеть
