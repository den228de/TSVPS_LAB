# Симуляция сети гиперкубов

Приложение для моделирования топологии сети гиперкубов и поиска кратчайших путей между процессорами.

## Быстрый старт

### Установка зависимостей

**Вариант 1 (рекомендуется):**
```bash
pip install -r requirements.txt
```

**Вариант 2:**
```bash
pip install matplotlib networkx
```

### Запуск приложения
```bash
python hypercube_gui.py
```

### Сборка в .exe
```bash
build_hypercube.bat
```

## Файлы проекта

- **hypercube_network.py** - основная логика (классы гиперкубов, алгоритм BFS)
- **hypercube_gui.py** - графический интерфейс
- **ЗАЩИТА_ГИПЕРКУБЫ.md** - руководство для защиты проекта
- **build_hypercube.bat** - скрипт сборки .exe файла

## Возможности

✅ Создание гиперкубов размерности 1-10  
✅ Объединение нескольких кубов в кольцевую топологию  
✅ Поиск кратчайшего пути (алгоритм BFS)  
✅ Визуализация графа с подсветкой пути  
✅ Подробная информация о топологии  

## Как использовать

1. Выберите метод поиска (один куб / несколько кубов)
2. Укажите размерность куба (1-10)
3. Укажите количество кубов
4. Нажмите "Создать сеть"
5. Введите ID исходного и конечного процессора
6. Нажмите "Найти путь"
