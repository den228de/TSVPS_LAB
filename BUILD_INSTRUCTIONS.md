# Быстрая инструкция по сборке EXE

## Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
pip install pyinstaller
```

## Шаг 2: Сборка EXE

### Автоматическая сборка (рекомендуется)
Просто запустите:
```bash
build_exe.bat
```

### Ручная сборка
```bash
pyinstaller --onefile --windowed --name="StonePartition" --hidden-import=matplotlib --hidden-import=matplotlib.backends.backend_tkagg --collect-data matplotlib --noconsole app.py
```

## Шаг 3: Найти EXE файл

После успешной сборки файл будет находиться в:
```
dist\StonePartition.exe
```

## Тестирование EXE

1. Скопируйте `StonePartition.exe` в отдельную папку
2. Запустите двойным кликом
3. Нажмите кнопку "▶ Запустить тестирование"
4. Дождитесь завершения и изучите графики

## Возможные проблемы

### Ошибка "Failed to execute script"
- Убедитесь, что все зависимости установлены
- Попробуйте пересобрать с флагом `--debug=all`

### EXE файл слишком большой
- Это нормально! Файл содержит Python и все библиотеки
- Обычный размер: 50-100 МБ

### Долгий запуск
- Первый запуск может занять 10-30 секунд
- Это нормально для приложений, собранных PyInstaller
