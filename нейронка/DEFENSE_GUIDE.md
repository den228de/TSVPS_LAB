## Введение

### Что такое искусственная нейронная сеть?

**Искусственная нейронная сеть (ИНС)** — это математическая модель, вдохновленная работой биологических нейронных сетей мозга. Она состоит из взаимосвязанных узлов (нейронов), которые обрабатывают информацию и обучаются на примерах.

### Основные компоненты:

- **Нейроны** — базовые вычислительные единицы
- **Связи (веса)** — определяют силу влияния одного нейрона на другой
- **Функция активации** — определяет выход нейрона
- **Слои** — группы нейронов (входной, скрытые, выходной)

---

## Теория нейронных сетей

### Персептрон

**Персептрон** — простейшая форма нейронной сети, состоящая из одного нейрона:

```
Вход → [Веса] → Σ (Сумматор) → Функция активации → Выход
```

**Формула:**
```
y = f(Σ(wi × xi) + b)
```
где:
- `xi` — входные значения
- `wi` — веса
- `b` — смещение (bias)
- `f` — функция активации

### Многослойный персептрон (MLP)

**Многослойный персептрон** — это нейронная сеть с несколькими слоями нейронов:

- **Входной слой** — принимает данные
- **Скрытые слои** — обрабатывают информацию (могут быть несколько)
- **Выходной слой** — выдает результат

### Функция активации: Сигмоида

В нашей реализации используется **сигмоидальная функция активации**:

```
σ(x) = 1 / (1 + e^(-x))
```

**Свойства сигмоиды:**
- Диапазон значений: (0, 1)
- Гладкая и дифференцируемая
- Используется для нормализации выходов

**Производная сигмоиды:**
```
σ'(x) = σ(x) × (1 - σ(x))
```

Наша нейронная сеть имеет следующую архитектуру:

```
┌─────────────┐

│    слой     │

       │ weights1 (10×100)
       ↓

│  Скрытый    │  100 нейронов

└──────┬──────┘
       │ weights2 (100×100)
       ↓

│   слой 2    │  (сигмоида)
└──────┬──────┘
       │ weights3 (100×10)
       ↓
┌─────────────┐
│  Выходной   │  10 нейронов
│    слой     │  (сигмоида)

```

### Параметры сети

| Параметр | Значение | Описание |
|----------|----------|----------|
| Входной слой | 10 нейронов | Принимает 10 входных значений |
| Скрытый слой 1 | 100 нейронов | Первый уровень обработки |
| Скрытый слой 2 | 100 нейронов | Второй уровень обработки |
| Выходной слой | 10 нейронов | Выдает 10 выходных значений |
| Всего весов | 10×100 + 100×100 + 100×10 = **11,000** | Обучаемые параметры |
| Функция активации | Сигмоида | Для всех слоев |
| Скорость обучения | 0.1 (по умолчанию) | Регулируемый параметр |

### Почему два скрытых слоя?

**Преимущества:**
- **Большая выразительность** — сеть может изучать более сложные зависимости
- **Иерархическое обучение** — первый слой изучает простые признаки, второй — более сложные
- **Универсальная аппроксимация** — теоретически может аппроксимировать любую функцию

## Алгоритмы работы

### 1. Прямое распространение (Forward Propagation)

**Цель:** Вычислить выход сети для заданного входа.

**Алгоритм:**

```
1. Входной слой = входные данные

2. Скрытый слой 1:
   для каждого нейрона j:
     sum = Σ(input[i] × weights1[i][j])
     hidden1[j] = sigmoid(sum)

3. Скрытый слой 2:
   для каждого нейрона j:
     sum = Σ(hidden1[i] × weights2[i][j])
     hidden2[j] = sigmoid(sum)

4. Выходной слой:
   для каждого нейрона j:
     sum = Σ(hidden2[i] × weights3[i][j])
     output[j] = sigmoid(sum)
```

**Код на Python:**
```python
def forward_propagation(self, input_data):
    self.input_layer = input_data
    
    # Скрытый слой 1
    hidden1_sum = np.dot(self.input_layer, self.weights1)
    self.hidden_layer1 = self.sigmoid(hidden1_sum)
    
    # Скрытый слой 2
    hidden2_sum = np.dot(self.hidden_layer1, self.weights2)
    self.hidden_layer2 = self.sigmoid(hidden2_sum)
    
    # Выходной слой
    output_sum = np.dot(self.hidden_layer2, self.weights3)
    self.output_layer = self.sigmoid(output_sum)
    
    return self.output_layer
```

### 2. Обратное распространение ошибки (Backpropagation)

**Цель:** Обновить веса сети для минимизации ошибки.

**Алгоритм:**

```
1. Вычисление ошибки выходного слоя:
   error_output = (expected - output) × sigmoid'(output)

2. Вычисление ошибки скрытого слоя 2:
   error_hidden2 = (error_output × weights3^T) × sigmoid'(hidden2)

3. Вычисление ошибки скрытого слоя 1:
   error_hidden1 = (error_hidden2 × weights2^T) × sigmoid'(hidden1)

4. Обновление весов (градиентный спуск):
   weights3 += learning_rate × (hidden2^T × error_output)
   weights2 += learning_rate × (hidden1^T × error_hidden2)
   weights1 += learning_rate × (input^T × error_hidden1)
```

**Математическая основа:**

Используется **метод градиентного спуска** для минимизации функции ошибки:

```
E = 1/2 × Σ(expected - output)²
```

Обновление весов:
```
w_new = w_old + η × ∂E/∂w
```
где `η` — скорость обучения (learning rate).

**Код на Python:**
```python
def backpropagate(self, expected_output):
    # Ошибка выходного слоя
    output_errors = (expected_output - self.output_layer) * \
                   self.sigmoid_derivative(self.output_layer)
    
    # Ошибка скрытого слоя 2
    hidden2_errors = np.dot(output_errors, self.weights3.T) * \
                    self.sigmoid_derivative(self.hidden_layer2)
    
    # Ошибка скрытого слоя 1
    hidden1_errors = np.dot(hidden2_errors, self.weights2.T) * \
                    self.sigmoid_derivative(self.hidden_layer1)
    
    # Обновление весов
    self.weights3 += self.learning_rate * \
                    np.outer(self.hidden_layer2, output_errors)
    self.weights2 += self.learning_rate * \
                    np.outer(self.hidden_layer1, hidden2_errors)
    self.weights1 += self.learning_rate * \
                    np.outer(self.input_layer, hidden1_errors)
```

### 3. Процесс обучения

**Алгоритм обучения:**

```
1. Инициализация весов случайными значениями [-0.5, 0.5]

2. Для каждой эпохи (epoch):
   a. Прямое распространение (вычисление выхода)
   b. Вычисление ошибки
   c. Обратное распространение (обновление весов)
   d. Сохранение ошибки для анализа

3. Повторять до достижения заданного числа эпох
```

**Метрика ошибки (MSE - Mean Squared Error):**
```
MSE = Σ(expected[i] - output[i])²
```

## Вопросы для защиты

### Теоретические вопросы

1. **Что такое нейронная сеть?**
   - Математическая модель, вдохновленная биологическими нейронными сетями

2. **Что такое функция активации?**
   - Функция, определяющая выход нейрона (в нашем случае — сигмоида)

3. **Что такое обратное распространение ошибки?**
   - Алгоритм обучения, который обновляет веса на основе градиента ошибки

4. **Зачем нужны скрытые слои?**
   - Для изучения сложных нелинейных зависимостей в данных

5. **Что такое скорость обучения (learning rate)?**
   - Параметр, определяющий размер шага при обновлении весов

### Практические вопросы

1. **Как работает прямое распространение?**
   - Данные проходят через слои, каждый нейрон вычисляет взвешенную сумму и применяет функцию активации

2. **Как вычисляется ошибка?**
   - MSE = Σ(ожидаемое - фактическое)²

3. **Как обновляются веса?**
   - По формуле градиентного спуска: w_new = w_old + learning_rate × gradient

4. **Почему используется сигмоида?**
   - Гладкая, дифференцируемая, нормализует выходы в диапазон (0, 1)

5. **Что показывает график ошибки?**
   - Процесс обучения: уменьшение ошибки с каждой эпохой
