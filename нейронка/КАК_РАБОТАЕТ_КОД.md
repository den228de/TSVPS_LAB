# КАК РАБОТАЕТ МОЯ ПРОГРАММА neural_network.py

## ОБЩАЯ СТРУКТУРА ПРОГРАММЫ

Моя программа состоит из **одного основного класса**:

**`NeuralNetwork`** - нейронная сеть с двумя скрытыми слоями

**Архитектура:** Вход (10) → Скрытый слой 1 (100) → Скрытый слой 2 (100) → Выход (10)

---

## ПОШАГОВОЕ ОБЪЯСНЕНИЕ РАБОТЫ ПРОГРАММЫ

### ШАГ 1: Создание нейронной сети (метод `__init__`)

**Что происходит при создании сети:**

```python
nn = NeuralNetwork(input_size=10, hidden_size1=100, hidden_size2=100, 
                   output_size=10, learning_rate=0.1)
```

1. **Сохранение параметров:**
   - `self.input_size = 10` (размер входного слоя)
   - `self.hidden_size1 = 100` (размер первого скрытого слоя)
   - `self.hidden_size2 = 100` (размер второго скрытого слоя)
   - `self.output_size = 10` (размер выходного слоя)
   - `self.learning_rate = 0.1` (скорость обучения)

2. **Создание слоев (массивов нулей):**
   - `self.input_layer` - массив из 10 нулей (входной слой)
   - `self.hidden_layer1` - массив из 100 нулей (первый скрытый слой)
   - `self.hidden_layer2` - массив из 100 нулей (второй скрытый слой)
   - `self.output_layer` - массив из 10 нулей (выходной слой)

3. **Инициализация весов случайными значениями:**
   - `self.weights1` - матрица 10×100 (связи: вход → скрытый слой 1)
   - `self.weights2` - матрица 100×100 (связи: скрытый слой 1 → скрытый слой 2)
   - `self.weights3` - матрица 100×10 (связи: скрытый слой 2 → выход)
   - Каждый вес инициализируется случайным числом от -0.5 до 0.5

**Всего весов:** 10×100 + 100×100 + 100×10 = **11,000 параметров**

---

### ШАГ 2: Прямое распространение (метод `forward_propagation`)

**Что происходит при прямом распространении:**

```python
output = nn.forward_propagation(input_data)
```

**Цель:** Пропустить данные через сеть и получить предсказание.

1. **Входной слой:**
   ```python
   self.input_layer = input_data  # Например: [0.82, 0.68, 0.58, ...]
   ```

2. **Первый скрытый слой:**
   ```python
   # Шаг 1: Умножаем входы на веса
   hidden1_sum = np.dot(self.input_layer, self.weights1)
   # Это даст массив из 100 чисел (по одному для каждого нейрона)
   
   # Шаг 2: Применяем сигмоиду
   self.hidden_layer1 = sigmoid(hidden1_sum)
   # Теперь каждое число в диапазоне (0, 1)
   ```
   
   **Что происходит:** Для каждого из 100 нейронов первого скрытого слоя:
   - Берем взвешенную сумму всех 10 входов
   - Применяем сигмоиду для нормализации

3. **Второй скрытый слой:**
   ```python
   # Шаг 1: Умножаем выходы первого скрытого слоя на веса
   hidden2_sum = np.dot(self.hidden_layer1, self.weights2)
   # Это даст массив из 100 чисел
   
   # Шаг 2: Применяем сигмоиду
   self.hidden_layer2 = sigmoid(hidden2_sum)
   ```
   
   **Что происходит:** Для каждого из 100 нейронов второго скрытого слоя:
   - Берем взвешенную сумму всех 100 выходов первого скрытого слоя
   - Применяем сигмоиду

4. **Выходной слой:**
   ```python
   # Шаг 1: Умножаем выходы второго скрытого слоя на веса
   output_sum = np.dot(self.hidden_layer2, self.weights3)
   # Это даст массив из 10 чисел
   
   # Шаг 2: Применяем сигмоиду
   self.output_layer = sigmoid(output_sum)
   # Это финальное предсказание!
   ```

**Итого:** Данные прошли через 4 слоя, 3 раза применили сигмоиду, получили предсказание.

### ШАГ 3: Обратное распространение ошибки (метод `backpropagate`)

**Что происходит при обратном распространении:**

```python
nn.backpropagate(expected_output)
```

**Цель:** Обновить веса, чтобы уменьшить ошибку.

1. **Вычисление ошибки выходного слоя:**
   ```python
   # Разница между ожидаемым и фактическим выходом
   output_errors = (expected_output - self.output_layer) * sigmoid_derivative(self.output_layer)
   ```
   
   **Что происходит:**
   - Вычисляем, насколько сильно ошиблись на выходе
   - Умножаем на производную сигмоиды (для градиента)

2. **Вычисление ошибки второго скрытого слоя:**
   ```python
   # Распространяем ошибку назад через веса
   hidden2_errors = np.dot(output_errors, self.weights3.T) * sigmoid_derivative(self.hidden_layer2)
   ```
   
   **Что происходит:**
   - Берем ошибку выходного слоя
   - Умножаем на транспонированные веса (идем назад)
   - Умножаем на производную сигмоиды

3. **Вычисление ошибки первого скрытого слоя:**
   ```python
   # Распространяем ошибку еще дальше назад
   hidden1_errors = np.dot(hidden2_errors, self.weights2.T) * sigmoid_derivative(self.hidden_layer1)
   ```

4. **Обновление весов (градиентный спуск):**
   ```python
   # Обновляем веса между скрытым слоем 2 и выходом
   self.weights3 += learning_rate * np.outer(self.hidden_layer2, output_errors)
   
   # Обновляем веса между скрытым слоем 1 и скрытым слоем 2
   self.weights2 += learning_rate * np.outer(self.hidden_layer1, hidden2_errors)
   
   # Обновляем веса между входом и скрытым слоем 1
   self.weights1 += learning_rate * np.outer(self.input_layer, hidden1_errors)
   ```
   
   **Формула обновления:**
   ```
   новый_вес = старый_вес + скорость_обучения × градиент
   ```

**Итого:** Прошли от выхода к входу, вычислили ошибки на каждом слое, обновили все веса.

### ШАГ 4: Обучение сети (метод `train`)

**Что происходит при обучении:**

```python
error_history = nn.train(input_data, expected_output, epochs=500)
```

**Цель:** Повторять прямое и обратное распространение много раз, чтобы сеть научилась.

1. **Начальное состояние (эпоха 0):**
   ```python
   # Делаем прямое распространение с начальными весами
   self.forward_propagation(input_data)
   
   # Вычисляем начальную ошибку
   initial_error = sum((expected_output - self.output_layer)²)
   # Обычно это большое число, например 2.5-3.0
   ```

2. **Основной цикл обучения (500 эпох):**
   ```python
   for epoch in range(1, 501):
       # Шаг 1: Прямое распространение
       self.forward_propagation(input_data)
       
       # Шаг 2: Обратное распространение (обновление весов)
       self.backpropagate(expected_output)
       
       # Шаг 3: Снова прямое распространение для проверки
       self.forward_propagation(input_data)
       
       # Шаг 4: Вычисление текущей ошибки
       current_error = sum((expected_output - self.output_layer)²)
       error_history.append(current_error)
   ```

3. **Результат:**
   - Начальная ошибка: ~2.5-3.0
   - Финальная ошибка: ~0.001-0.01
   - **Улучшение: ~99%**

**Итого:** За 500 эпох сеть постепенно подстраивает веса, ошибка уменьшается.

> 
> **Первый этап** - инициализация сети. Я создаю класс `NeuralNetwork` с четырьмя слоями: входной на 10 нейронов, два скрытых слоя по 100 нейронов каждый, и выходной на 10 нейронов. В конструкторе я создаю массивы для каждого слоя и инициализирую три матрицы весов случайными значениями от минус 0.5 до 0.5. Всего получается 11 тысяч обучаемых параметров.
> 
> **Второй этап** - прямое распространение. Я беру входные данные и последовательно пропускаю их через все слои. Выход одного слоя становится входом следующего. В конце получаю предсказание на выходном слое.
> 
> **Третий этап** - обратное распространение ошибки. Сначала я вычисляю ошибку на выходном слое как разницу между ожидаемым и фактическим результатом, умноженную на производную сигмоиды. Затем распространяю эту ошибку назад через сеть, умножая на транспонированные матрицы весов. Для каждого слоя получаю градиент ошибки. После этого обновляю все веса по формуле градиентного спуска: новый вес равен старому весу плюс скорость обучения, умноженная на градиент.
> 
> **Четвертый этап** - обучение. Я повторяю прямое и обратное распространение заданное количество эпох, например 500 раз. На каждой эпохе веса немного корректируются в сторону уменьшения ошибки. Я сохраняю историю ошибок, чтобы видеть процесс обучения. В начале ошибка большая, около 2-3, а в конце уменьшается до 0.001-0.01, то есть сеть обучается с точностью около 99 процентов."

## КЛЮЧЕВЫЕ МОМЕНТЫ ДЛЯ ЗАПОМИНАНИЯ

✅ **Архитектура:** 10 → 100 → 100 → 10 (всего 11,000 весов)  
✅ **Сигмоида:** `σ(x) = 1 / (1 + e^(-x))` - нормализует в диапазон (0, 1)  
✅ **Производная сигмоиды:** `σ'(x) = σ(x) × (1 - σ(x))` - нужна для градиента  
✅ **Прямое распространение:** вход → взвешенная сумма → сигмоида → следующий слой  
✅ **Обратное распространение:** ошибка выхода → распространяем назад → обновляем веса  
✅ **Градиентный спуск:** `w_new = w_old + learning_rate × gradient`  
✅ **Обучение:** повторяем прямое + обратное распространение много раз (эпох)  
✅ **MSE (ошибка):** `sum((expected - actual)²)` - чем меньше, тем лучше

## ФУНКЦИЯ АКТИВАЦИИ: СИГМОИДА

### Что это:
```python
def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))
```

### Зачем нужна:
- **Нормализация:** Любое число превращает в диапазон (0, 1)
- **Нелинейность:** Позволяет сети изучать сложные зависимости
- **Гладкость:** Можно вычислить производную для обучения

### Примеры:
```
sigmoid(0) = 0.5      (нейтральное значение)
sigmoid(5) ≈ 0.993    (большое положительное → близко к 1)
sigmoid(-5) ≈ 0.007   (большое отрицательное → близко к 0)
```

### Производная:
```python
def sigmoid_derivative(x):
    return x * (1.0 - x)  # где x уже прошел через sigmoid
```

**Зачем производная:** Она показывает, как быстро меняется сигмоида в данной точке. Это нужно для вычисления градиента при обратном распространении.

## МАТРИЧНЫЕ ОПЕРАЦИИ

### np.dot (умножение матриц):
```python
hidden1_sum = np.dot(input_layer, weights1)
# input_layer: [10 чисел]
# weights1: [10×100 матрица]
# Результат: [100 чисел] - по одному для каждого нейрона
```

**Что происходит:** Для каждого нейрона скрытого слоя вычисляется взвешенная сумма всех входов.

### np.outer (внешнее произведение):
```python
weight_update = np.outer(hidden_layer2, output_errors)
# hidden_layer2: [100 чисел]
# output_errors: [10 чисел]
# Результат: [100×10 матрица] - обновление для каждого веса
```

**Что происходит:** Создается матрица, где каждый элемент - это произведение соответствующих элементов из двух векторов.

## ПОЧЕМУ ДВА СКРЫТЫХ СЛОЯ?

1. **Первый слой** - изучает простые признаки (например, края, линии)
2. **Второй слой** - комбинирует простые признаки в сложные (например, формы, паттерны)
3. **Выходной слой** - принимает финальное решение

**Аналогия:** Как человек учится распознавать лица:
- Слой 1: видит линии и точки
- Слой 2: комбинирует их в глаза, нос, рот
- Выход: определяет конкретное лицо
