# 🧠 Нейронная сеть с двумя скрытыми слоями

Приложение для обучения и тестирования нейронной сети с графическим интерфейсом.

## 📋 Описание

Реализация многослойной нейронной сети на Python с визуализацией процесса обучения.

**Архитектура:** 10 → 100 → 100 → 10 (входной слой → скрытый слой 1 → скрытый слой 2 → выходной слой)

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск приложения

```bash
python neural_network_gui.py
```

### Сборка EXE

```bash
build_neural_network.bat
```

Готовый файл будет в папке `dist/NeuralNetwork.exe`

## 📊 Параметры сети

| Параметр | Значение |
|----------|----------|
| Входной слой | 10 нейронов |
| Скрытый слой 1 | 100 нейронов |
| Скрытый слой 2 | 100 нейронов |
| Выходной слой | 10 нейронов |
| Функция активации | Сигмоида |
| Алгоритм обучения | Backpropagation |

## 💡 Использование

1. Запустите приложение
2. Настройте параметры (количество эпох, скорость обучения)
3. Нажмите "Обучить сеть"
4. Наблюдайте за процессом обучения на графике
5. Протестируйте сеть на новых данных

## 📝 Пример кода

```python
from neural_network import NeuralNetwork
import numpy as np

# Создание сети
nn = NeuralNetwork(10, 100, 100, 10, learning_rate=0.1)

# Обучение
train_input = np.array([0.82, 0.68, 0.58, 0.52, 0.5, 0.52, 0.58, 0.68, 0.82, 1.0])
train_output = np.array([0.82, 0.68, 0.58, 0.52, 0.5, 0.52, 0.58, 0.68, 0.82, 1.0])
error_history = nn.train(train_input, train_output, epochs=500)

# Тестирование
test_input = np.array([0.28, -0.28, -0.68, -0.92, -1.0, -0.92, -0.68, -0.28, 0.28, 1.0])
prediction = nn.predict(test_input)
```
