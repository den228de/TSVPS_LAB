# Рекомендуемые настройки для GUI

## ⚙️ Оптимальные параметры

После тестирования, вот лучшие настройки:

### Параметры обучения:
- **Скорость обучения:** `0.1` ✅
- **Количество эпох:** `50` (не 500!)

### Почему 50 эпох, а не 500?

Программа теперь обучается на **200 случайных примерах** внутри, поэтому:
- 50 эпох × 200 примеров = **10,000 итераций обучения**
- Этого достаточно для отличных результатов
- Обучение занимает ~10-15 секунд вместо минуты

### Обучающие данные (по умолчанию):
```
Входные: 0.82, 0.68, 0.58, 0.52, 0.5, 0.52, 0.58, 0.68, 0.82, 1.0
Выход:   0.82, 0.68, 0.58, 0.52, 0.5, 0.52, 0.58, 0.68, 0.82, 1.0
```

### Тестовые данные (по умолчанию):
```
0.28, 0.15, 0.32, 0.08, 0.0, 0.08, 0.32, 0.72, 0.28, 1.0
```

## 📊 Ожидаемые результаты

С этими настройками ты получишь:
- **Ошибка на обучении:** ~0.01
- **Ошибка на тесте:** ~0.01-0.02
- **Максимальная разница:** ~0.08

## 🚀 Сборка EXE

Для сборки приложения запусти:
```bash
.\build_neural_network.bat
```

Или вручную:
```bash
pyinstaller --noconfirm --onefile --windowed --name "NeuralNetwork" --add-data "neural_network.py;." --hidden-import "numpy" --hidden-import "matplotlib" --hidden-import "tkinter" --collect-all matplotlib neural_network_gui.py
```

EXE файл будет в папке `dist\NeuralNetwork.exe`
